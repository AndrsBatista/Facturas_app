# Facturas-App

Aplicación web desarrollada con Django (Python) para la gestión de facturas de clientes.

# Funcionalidades

- Crear, editar y eliminar facturas
- Registro de clientes y productos
- Cálculo de montos totales
- Validación de formularios
- CRUD completo con Django Admin
- Conexión a base de datos (SQLite o PostgreSQL)
- Login con Django Authentication

# Tecnologías utilizadas

- Python 
- Django
- HTML
- Bootstrap
- PostgreSQL
- Docker
